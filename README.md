### The Backstory
I dug up this relic from back in 9th grade. My school organized an open-age software design competition to celebrate its 100th anniversary, and somehow, I actually ended up winning 1st place for both Best Developer and Best Designer. I have no clue where the physical certificate is nowadays, but the codebase survives.

If you look at the source code, please shield your eyes. The backend is completely, shamelessly hardcoded. The competition had a rule where we could only use Python's built-in libraries, but the real reason it's built like this is that I didn't actually know how to code properly yet. Instead of doing things the right way, I just brute-forced everything out of sheer willpower.

But hey, the UI still looks surprisingly clean, proving the oldest rule in tech: if you don't know how to build a proper backend, just make the frontend look pretty.

### The Grind
I vividly remember the absolute grind for this thing. I spent about two months straight working on it for 6 hours a day, basically teaching myself how to debug on the fly until my head hurt.

Did it take me way longer than it should have? Yes. Is the code a complete mess? Absolutely. But I stuck with it because I just loved building stuff.

Even though looking at this code now gives me minor emotional damage, it's really satisfying to look back on. It’s awesome to remember that energy and see exactly where I started out.
